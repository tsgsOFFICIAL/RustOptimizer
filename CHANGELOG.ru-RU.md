# Список изменений

Здесь документируются все значимые изменения в Rust Optimizer.

## 0.14.1

### Исправления

- Исправлено: обновления, установленные через инсталлятор, не открывали приложение заново после установки. Обновление полагалось на диспетчер перезапуска Inno Setup, который должен был заново запустить приложение после установки новой версии, но он перезапускает только те процессы, которые всё ещё работали в момент, когда он проверял заблокированные файлы - а поскольку приложение само завершало работу сразу после запуска инсталлятора, к этому моменту оно почти никогда не было запущено. Теперь обновление само дожидается завершения работы инсталлятора и заново запускает приложение.

## 0.14.0

### Привязки клавиш

Новая страница **Привязки клавиш**: все текущие привязки из `keys.cfg`, сгруппированные по сворачиваемым категориям (свёрнуты по умолчанию, поэтому страница открывается компактной, а не одним длинным списком), с мгновенным поиском, который разворачивает результаты по всем категориям сразу.

- **Выбрать из списка** - каталог всех реальных действий Rust с поиском, проверенных по собственным стандартным привязкам игры, с описанием и точной консольной командой, показанными до того, как вы её выберете.
- **Создать вручную** - конструктор многостадийных макросов для переключающихся привязок (как встроенные переключатели звука/угла обзора в самой игре), со слайдерами, переключателями и текстовыми полями для тех немногих convar'ов, которые это поддерживают, либо полем для произвольной команды для всего остального. «Загрузить пример» заполняет конструктор несколькими реальными, рабочими макросами, которые можно изменить, вместо того чтобы писать с нуля.
- Визуальный выбор клавиши и кнопки мыши - нажмите на клавишу или просто нажмите её (или комбинацию клавиш) на настоящей клавиатуре - с отображением занятости в реальном времени и предупреждением, если у голой клавиши комбинации уже есть своя отдельная привязка, поскольку в Rust срабатывают обе.

### Исправления

- Исправлено: ни одна кнопка в окне выбора клавиши - включая «Отмена» и «Использовать всё равно» в окне конфликта - не реагировала на нажатие. Обработчик на уровне окна, который должен был позволять выбрать клавишу физическим нажатием, перехватывал каждый клик мыши и интерпретировал его как «нажата кнопка мыши 1», поскольку обычный клик и физическое нажатие кнопки мыши - одно и то же событие. Кнопки мыши больше не перехватываются таким образом - у каждой уже есть своя кликабельная клавиша на схеме мыши.
- Исправлено: клавиши цифрового блока («Numpad 7» и т.д.) обрезались до нескольких букв, а схема мыши полностью обрезалась по краю окна. Общая ширина клавиатуры была задана жёстко и не учитывала ширину собственной самой широкой строки, незаметно отнимая место, предназначенное для панели мыши.
- Исправлено: вручную созданный макрос с двумя и более командами на одной стадии цикла давал некорректную командную строку, если одна из команд (например, сообщение на экране) уже содержала кавычки - кавычки не экранировались при вложении в синтаксис группировки.
- Исправлено: значок «удалить эту команду» в конструкторе вручную отображался прижатым к левому верхнему углу кнопки вместо центра - для него не было задано собственное выравнивание, поэтому применялось значение по умолчанию вместо реального центрирования. Также отдельно исправлено: собственный элемент значения слайдера отображался заметно ниже, чем остальная часть его строки - высота слайдера по умолчанию оставляла в его же шаблоне место сверх того, что реально занимают дорожка и ползунок.

## 0.12.1

### Исправления

- Исправлено: страница «Система» и панель управления показывали меньше ОЗУ, чем установлено на самом деле (например, «61.6 ГБ» для комплекта на 64 ГБ), а также некорректно предупреждали, что рекомендуется 16 ГБ или больше, даже когда было установлено ровно 16 ГБ. Теперь оба места используют фактическую заявленную производителем ёмкость модулей ОЗУ вместо значения, которое Windows сообщает как доступное - оно всегда немного меньше из-за памяти, зарезервированной для прошивки, встроенной графики и чипсета.

## 0.12.0

### Оптимизация автозагрузки подключена

Кнопка **«Оптимизировать автозагрузку»** на панели управления теперь открывает Диспетчер задач, где Windows уже показывает реальное влияние каждого приложения на запуск. Нет поддерживаемого способа сразу попасть на вкладку автозагрузки или получить её отсортированной по влиянию - Windows не предоставляет для этого никакого хука, - так что это просто приводит вас к нужному инструменту, а не изображает контроль, которого у нас нет.

### Исправления

- Исправлено: длинный заголовок диалога (например, «Требуется разрешение администратора») выходил за край окна и накладывался на кнопки свёртывания/закрытия. Заголовку не хватало места для длинного текста рядом с названием приложения и версией - диалоги подтверждения и ввода имени профиля теперь достаточно широкие и растягиваются по высоте под сообщение вместо того, чтобы обрезать его.

## 0.11.0

### Обновление драйверов подключено

Кнопка **«Обновить драйверы»** на панели управления теперь работает. Однако Rust Optimizer пока, к сожалению, не может достоверно определить, доступно ли обновление драйвера на самом деле. Не существует единого источника, который отслеживал бы последнюю версию для каждого устройства, поэтому вместо этого он показывает, что обнаружено в вашей системе, и даёт прямые ссылки, где это проверить.

- Прямые ссылки для вашего **процессора**, **видеокарты** и **материнской платы**, определённые по производителю (Intel/AMD/NVIDIA, а также ASUS/MSI/Gigabyte/ASRock для материнских плат). В зависимости от вашего оборудования.
- Строка **«Другие драйверы»** ведёт к разделу необязательных обновлений Windows Update, который охватывает звук, сеть, чипсет и всё остальное вне этих трёх категорий.

## 0.10.4

### Профили графики

![Профили графики](https://raw.githubusercontent.com/tsgsOFFICIAL/RustOptimizer/master/Assets/Changelog/graphics-profiles.gif)

На странице «Графика» теперь есть выбор профиля, доступный по ссылке **«Управление профилями»** на панели управления. Выберите Low End PC, Competitive или Cinematic - и все ползунки встанут в соответствующее положение; сдвиньте ползунок после этого, и он будет отмечен как несохранённый, чтобы вы всегда знали, действительно ли то, что вы видите, применено на самом деле.

- **Сохраняйте собственные профили** - настройте ползунки из любого исходного положения и сохраните результат под собственным именем. При выборе сохранённого профиля позже применяются именно эти настройки.
- **Переименовывайте и удаляйте** собственные профили. Три встроенных пресета изменить нельзя.
- Если ваши ползунки случайно совпадут с настройками одного из встроенных пресетов, выбор распознает это как этот пресет, а не позволит сохранить дубликат.
- **Качество теней и качество воды теперь имеют три по-настоящему разных уровня.** Раньше «Среднее» было идентично «Низкому» у обоих под капотом, поэтому переключение между ними ничего не меняло. «Среднее» теперь стало отдельной, самостоятельной настройкой.

## 0.10.3

Очистка кэша была проверена на реальной машине с AMD и на действующей установке Steam, и оказалось, что нескольких мест, куда она заглядывала, попросту не существует. Теперь она очищает заметно больше.

- **Теперь очищается встроенный браузер Steam** - через него кэшируются магазин, сообщество и оверлей, и он вырос примерно до 500 МБ, ни разу не будучи затронутым. Обычно это самое крупное, что освобождает очистка кэша. Ваш вход в аккаунт и настройки магазина не затрагиваются.
- **Кэш депо Steam не очищался никогда** - его искали на одну папку в стороне от того места, где он действительно находится. Около 55 МБ при типичной установке.
- Теперь также очищаются папка загрузок Steam и его аварийные дампы. Обложки игр и собственные журналы Steam намеренно не трогаются: обложки придётся скачивать заново, а журналы запрашивает поддержка Steam.
- **Очищается больше шейдерных кэшей AMD** - Vulkan, OpenGL и DirectX 9, а также ещё один кэш DirectX, который пропускался полностью. Кэш OpenGL раньше искали под названием, которое использует NVIDIA, поэтому на машине с AMD он не находился никогда, а одна из папок просто не существует ни в одном драйвере.
- **Журналы Unity для Rust теперь действительно очищаются.** Их искали в папке `Facepunch`, тогда как Rust пишет в `Facepunch Studios LTD`, поэтому `Player.log` не удалялся ни разу - а поскольку он ничем не ротируется, он растёт всё время существования установки.
- Журналы Rust теперь очищаются до временных файлов Windows, а не после. Одно из мест хранения журналов находится внутри папки временных файлов, поэтому при прежнем порядке шаг очистки временных файлов уже удалял её, а шаг журналов сообщал, что ничего не нашёл.

## 0.10.0

### «Настройки» переработаны

![Настройки](https://raw.githubusercontent.com/tsgsOFFICIAL/RustOptimizer/master/Assets/Changelog/settings-page.gif)

Параметры сгруппированы по разделам **«Внешний вид»**, **«Приложение»**, **«Обновления»**, **«Единицы измерения»** и **«Данные»** - и каждый пункт теперь объясняет, что он делает, а не просто называется.

- **Тема и язык - выпадающие списки** - аккуратнее по мере добавления языков, и рядом с каждым языком показан его флаг.
- **Запуск вместе с Windows** - открывает Rust Optimizer при входе в систему. Настройка для текущего пользователя, права администратора не запрашиваются.
- **Настройки обновлений** - проверять новую версию при запуске и при желании устанавливать её автоматически. Автоустановка отключена по умолчанию, так как обновление перезапускает приложение.
- **Единицы скорости сети** - `МБ/с` под размеры файлов или `Мбит/с` под то, как рекламируют соединения. Страница «Сеть» следует вашему выбору.
- **Настройки журналов** - хранить журналы 7, 30 или 90 дней, открыть папку с журналами и включить **подробное логирование**.

> Включайте подробное логирование *до* воспроизведения проблемы. Тогда журнал покажет, что именно делало приложение - какие пути оно проверяло, что нашло и сколько занял каждый шаг.

> **Важно:** при обновлении тема и язык один раз сбросятся к значениям по умолчанию. Все настройки теперь хранятся в одном файле, а старые значения не переносятся. Выберите их заново - дальше они будут сохраняться.

## 0.9.0
- В «Быстрые действия» на панели управления добавлена **«Очистить кэш»**: очищает временные файлы Windows, кэш шейдеров видеокарты (NVIDIA, AMD, Intel и DirectX), кэш загрузок, депо и магазина Steam, журналы Unity в Rust и аварийные дампы приложений - а затем показывает под кнопкой, сколько места действительно освободилось.
- «Очистить кэш» спрашивает перед запуском, и три пункта можно отключить заранее: очистку корзины, очистку кэша эскизов (при которой Проводник ненадолго перезапускается) и включение системных файлов (для чего запрашивается подтверждение администратора). Всё остальное удаляется безопасно и восстанавливается само.
- «Очистить кэш» показывает ход выполнения и называет каждую группу по мере работы, а очистку можно остановить на полпути - прерванная очистка всё равно сообщает, сколько успела освободить.
- «Очистить кэш» не трогает кэш шейдеров, пока запущен Rust - и сообщает об этом, вместо того чтобы молча освободить меньше, чем вы ожидали. Файлы, которые действительно заняты, пропускаются и подсчитываются, а не считаются ошибкой.
- После очистки кэша шейдеров Rust может запускаться чуть дольше в первый раз, пока они пересобираются. Это ожидаемо, и об этом сказано в самом окне.
- Добавлена страница **«Сеть»**: сведения об активном адаптере в реальном времени (скорость соединения, локальный IPv4/шлюз/MAC/DNS), постоянно обновляемые пинг и джиттер до 1.1.1.1, живая скорость загрузки/отдачи и опциональная проверка публичного IP, которую вы запускаете сами, а не она выполняется автоматически - плюс ссылка на Speedtest.net для полного теста скорости и задержки.
- Добавлены три настройки на странице «Сеть» - отключение ограничения сети Windows, энергосбережения адаптера и резервирования пропускной способности QoS - каждая из которых при применении кратко показывает запрос администратора, так как эти настройки требуют повышенных прав.
- Добавлен значок предупреждения на странице «Сеть», когда активное соединение - это Wi-Fi, а не проводной Ethernet, поскольку кабель даёт заметно более низкую и стабильную задержку.
- Плитка «Сеть» в Обзоре оптимизации на Панели управления теперь привязана к реальным настройкам страницы «Сеть» вместо жёстко заданной заглушки «8 / 10 настроек», как уже работает плитка «Система».

## 0.8.8
- Добавлена страница **«Графика»**: упрощённые ползунки качества (Качество теней, Качество текстур, Качество эффектов, Дальность прорисовки, Детализация мира, Качество воды, Отображение инвентаря), каждый из которых сразу записывает значения в `client.cfg` - те же значения convar, что уже использует пресеты профилей, теперь их можно менять по одной настройке за раз, а не только целыми пакетами.

## 0.8.7
- Добавлена страница **«Геймплей»**: подборка дополнительных настроек `client.cfg`, улучшающих видимость и чёткость без ущерба производительности, разделённая на «Рекомендуется всем» (без реальных минусов для кого-либо) и «На ваш вкус» (дело личных предпочтений) - каждую настройку можно включать/выключать отдельно, а у каждого раздела есть общий переключатель, включающий или выключающий всё сразу.
- Переключение настройки на странице «Геймплей» теперь сразу записывается в `client.cfg` без создания полной резервной копии при каждом переключении, в отличие от готовых профилей - переключение нескольких настроек туда-сюда больше не заваливает историю резервных копий мусорными записями.
- В список ресурсов на странице «Утилиты» добавлено приложение Raidboi-1129 (iOS и Android) - мобильный калькулятор стоимости рейда и добычи для Rust.
- Убран пресет «Стример» из готовых профилей (теперь Слабый ПК, Соревновательный и Кинематографичный), чтобы сократить количество вариантов выбора.
- На странице «Система» добавлена карточка «Дисплей»: текущая и максимальная частота обновления и разрешение, отмечаются значком предупреждения и подсказкой, если что-то из этого работает ниже того, что реально поддерживает монитор - например, монитор на 144 Гц, застрявший на 60 Гц, или 4K-монитор, работающий в 1080p.
- Добавлены недостающие датский и русский переводы для всей страницы «Резервное копирование» и её диалогов подтверждения, которые ранее незаметно переключались на английский.
- Исправлено то, что метки темы «Светлая/Тёмная/Системная» на странице «Настройки» и подсказки «Восстановить/Удалить» на странице «Резервное копирование» были жёстко заданы на английском независимо от выбранного языка.

## 0.8.6
- Удалена отдельная страница «Конфигурации» - она объединена с новой страницей резервного копирования, поскольку обе страницы, по сути, занимались одним и тем же: управлением cfg-файлами Rust.
- Добавлена страница резервного копирования: переключение между «Настройками» (`client.cfg`) и «Клавишами» (`keys.cfg`), просмотр истории резервных копий для каждого типа, создание резервной копии с собственным названием (или оставьте поле пустым для метки времени), а также восстановление или удаление любой записи - оба действия сначала запрашивают подтверждение, так как удаление нельзя отменить.
- Резервные копии теперь создаются автоматически перед применением готового профиля и перед восстановлением, которое перезаписывает текущий файл - это заменяет старую единственную копию `client.cfg.bak`, которая хранила только одну версию.
- Кнопки предустановленных профилей на панели управления теперь заблокированы, если Rust не установлен, вместо того чтобы оставаться кликабельными без какого-либо эффекта.
- Карточка «Накопители» на странице «Система» теперь обновляется каждые несколько секунд, а не только при открытии страницы.
- Исправлено: фон кнопок при наведении по всему приложению показывал резкие прямые углы вместо повторения скруглённой формы самой кнопки.

## 0.8.5
- Добавлена страница «Система» (доступна из боковой панели): текущая загрузка и характеристики процессора/видеокарты/ОЗУ, материнская плата/BIOS, накопители и данные ОС, а также настройки уровня ОС - схема электропитания, точность указателя, Игровой режим, фоновая запись и полноэкранные оптимизации для Rust.

- Карточка «Система» в обзоре оптимизации на панели управления теперь связана с реальными настройками страницы «Система» вместо жёстко заданного значения «12 / 16 settings», и получила трёхуровневый статус (красный/жёлтый/зелёный) вместо простого деления хорошо/не оптимизировано.
- Затемнены карточки «Производительность», «Сеть» и «Графика» в обзоре оптимизации (пока тестовые данные) - теперь они выглядят так же, как другие ещё не реализованные функции, и только карточка «Система» выглядит интерактивной.
- Карточка «Система» в обзоре оптимизации теперь кликабельна и сразу открывает страницу «Система» - то же место, куда ведёт строка «Подробнее» в карточке «Информация о системе».
- Исправлено: подсказка у значков предупреждения иногда появлялась только после того, как курсор несколько раз перемещали туда-сюда.
- Исправлено: счёт «Система» на панели управления не обновлялся после изменения настройки на странице «Система» до перезапуска приложения.
- Добавлена поддержка ~~зачёркнутого текста~~ в отображении списка изменений.
